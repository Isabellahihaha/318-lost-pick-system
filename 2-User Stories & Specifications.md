Pick Service
User Story B1. Create/get/update/delete an item

    As a User, I want to create a new item record with details such as name, colour, statues and location
    As a User, I want to get a item's information by its name
    As a Admin, I want to update an existing item's information by its name
    As a Admin, I want to delete a item record by its name.

User Story B2: List All items

    As a User/Admin, I want to retrieve a list of all books.

Library Service
User Story L1: Find by Item name
    As a User/Admin, I want to find libraries in which a book with a specific ISBN is available.

User Story L2: Check item Statues

    As a User/ Admin, I want to check the statues for a specific item.

User Story L3: Match an item

    As a User / Admin, I want to match an item with specific conditions.
